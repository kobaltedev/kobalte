# Server-side rendering

Kobalte works with any Solid 2 SSR setup as long as the environment is configured correctly.

## Usage with SolidStart

Kobalte works with [SolidStart](https://start.solidjs.com/) and other Solid 2 SSR setups. Use `@solidjs/web` as your JSX import source and run SSR through `@solidjs/vite-plugin`'s start mode.

:::info
Kobalte 2 targets `solid-js@^2.0.0` and `@solidjs/web@^2.0.0`. This documentation site is built with `@kobalte/solidbase@2` and `@solidjs/vite-plugin@3`; see its `vite.config.ts` and `src/app.tsx` for a working setup.
:::
