# Server Side Rendering

Kobalte should work with any SSR for SolidJS, please make sure the environment is correctly setup.

## Usage with SolidStart

Kobalte works out of the box with [SolidStart](https://start.solidjs.com/).

:::info
Kobalte has been tested with `solid-js@1.9.9`, `@solidjs/start@0.6.1`, and `@solidjs/start@2.0.0-alpha.3`.
:::
